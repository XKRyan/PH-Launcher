PH Launcher Mac 安装与首次打开帮助

认准窗口里的 App · Apple 芯片与 Intel Mac 通用

如果你使用的是未签名测试版

未签名测试版只有 ad-hoc 临时签名，没有 Developer ID 身份签名且未经 Apple 公证。macOS 无法确认开发者身份，也无法像正式公证版一样确认文件发布后是否被改动。运行未经 Developer ID 签名和公证的软件可能损害电脑或泄露隐私。

测试版仅从 PH Launcher 官方 GitHub 仓库下载，并核对同一下载页提供的 SHA-256 清单。SHA-256 只能帮助发现文件不一致，不能替代 Developer ID 签名或 Apple 公证。如果来源或校验结果不确定，请删除测试包。

安装

  1. 在 DMG 安装窗口中，按住左侧、名称为 PH Launcher 的 App 图标。不要拖桌面上名称含“安装盘”或版本号的磁盘图标。
  2. 把这个 App 放到同一窗口右侧的蓝色 Applications 图标。不要把 Applications 文件夹拖到桌面。
  3. 如果拖动不方便：选中窗口左侧 App，按 ⌘C；再从 Finder 侧栏打开“应用程序”，按 ⌘V。
  4. 复制完成后推出 PH Launcher 安装盘，再从“应用程序”文件夹打开 PH Launcher。

未签名测试版被 macOS 阻止首次打开时

  1. 打开苹果菜单中的 系统设置。
  2. 进入 隐私与安全性，向下滚动到“安全性”。
  3. 找到 PH Launcher 的提示，点按 仍要打开，然后在再次出现的提示中确认“打开”。系统可能要求输入当前 Mac 的登录密码。

Apple 说明，“仍要打开”按钮通常会在你尝试打开 App 后约一小时内显示。成功确认一次后，PH Launcher 会被保存为这台 Mac 的安全性例外。

查看 Apple 官方说明：打开来自未知开发者的 Mac App

不要降低系统安全性

本测试版不需要运行任何终端命令，也不需要关闭 macOS 的安全功能。若你看到来源不明的教程要求这样做，请停止操作并向项目维护者反馈。
