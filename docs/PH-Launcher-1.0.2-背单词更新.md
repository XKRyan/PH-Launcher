# PH Launcher 1.0.2 · 背单词更新

## 词书与阅读

- 背单词页面右上角新增「导入词书」，支持粘贴词表、导入已有学习备份。
- 「获取推荐词书」直达托福、雅思等离线参考词单。不是官方考试词书，无需付费下载。
- 「阅读积累」支持 Word（.docx）、PDF、TXT、Markdown，也可以直接粘贴文字。先预览、核对，再保存并阅读。
- 文档在本机提取，不上传，不运行宏。单文件上限 20 MB、PDF 上限 200 页，每篇阅读最多 20000 字符；超长内容会明确提示只提取了前一部分。
- 旧版 .doc 请另存为 .docx；扫描 PDF 需要先 OCR。图片、批注、复杂排版不保证包含在提取文本中。

## 学习节奏

每组收集 5 个不熟悉的词：点击「我会这个词」会跳过并补入下一个词，不占用已完成新词的额度，也不会伪造复习记录。看完一组后，填空顺序重新打乱。词源或当日额度不足时，最后一组按实际数量学习。

有完整例句的词使用语境填空；缺少有效例句时会明确提示，改用看词回忆，不编造空缺题。

## AI 连接

「下一组推荐 → 连接与检查」可选择本地或 API，并测试当前连接。沿用 AI 学习助手中已经保存的模型与 Key，无需重复填写。

- 本地 AI 请求可按需启动已安装的默认 Ollama 服务；不会自动安装或下载模型。API 模式启动程序时仍不启动本地 AI。
- 模型首次加载最多等待 90 秒，可以立即改为离线学习或取消。连接失败会显示可操作的原因。
- 改进例句要求，并兼容带 JSON 代码块的有效响应。
- API 需要单独确认，可能产生费用；重启后需再次授权。仅发送限定的词汇学习信号，不发送阅读原文或学校数据，也不会在本地失败时自动切换 API。

本次提供 Windows 1.0.2，尚未同步生成 Mac 1.0.2。学校选课自动识别功能继续保留。
