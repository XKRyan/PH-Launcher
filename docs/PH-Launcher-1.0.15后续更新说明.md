# PH Launcher 1.0.15 之后的更新

本文说明分支 `fix/manual-course-selection` 在 1.0.15（`merge/school-integrations-into-main`）之上做的改动，共 15 个提交。版本号仍是 1.0.15，尚未发版。

## 界面变化

- 新图标：象牙白圆角底，衬线体 PHL，PH 深绿、L 金色。安装包、任务栏、侧栏和启动页用的是同一套图。
- 删除“班级课表”。侧栏学校应用只剩四项：我的课表、我的日程、我的课程、平和邮箱。旧的快捷方式或 AI 跳转会打开“我的课表”。AI 仍可读取全班课表数据。
- 侧栏的“背单词”换成 VLMReader 入口。已安装就直接打开，没有安装则显示下载页（默认走 GH-Proxy 镜像，也可选 GitHub 官方源）。进入页面不会自动下载。旧的背单词记录保留，仍可导出。
- 窗口较矮（高度不超过 760px）时，侧栏的专注卡片收成一行，能多显示两行导航。
- 设置 → 通用里，“界面语言”一行不再跑到标题上面。
- VLMReader 页改成和其他页面一致的标题区与卡片样式。
- 侧栏底部的“使用导览”改为次要文字样式，不再比“设置”更醒目。

## 问题修复

- 手动取消的课程，重启后又被选回来：共享配置里 `lessons` 段的列表项写在第 0 列时没有被整段替换，旧条目残留后被重新读出。现在会整段替换，CRLF 换行也能识别。
- 学校密码错误时会反复自动登录：每一轮云同步都会重新提交同一个错误密码，大约每分钟一次，可能导致 ManageBac 锁号。现在同一组账号密码只自动提交一次，改了账号或密码、手动登录或重启后才会再试。
- phix 长轮询在重新登录或保存设置后会一条条叠加，占用服务端连接并造成重复同步。现在只保留一条。
- 数据文件读取失败且备份也没复制成功时，原来会用默认值覆盖用户唯一的数据。现在这种情况下本次运行不保存，下次启动重新读取原文件。
- 其他小问题：AI 历史不再要求系统加密可用；本地 AI 预热的取消逻辑恢复正常；开机画面的计时器会及时清除；测试用临时目录在退出时清理。

## 安全

- 记住的 phix 密码不再发送给界面进程，也不会写进导出的备份。
- 主窗口只显示启动器自己的页面。AI 回复里的链接会交给系统浏览器打开，不会把启动器窗口换成外部网页。
- 读写本地数据、导出、安装本地 AI、打开链接等敏感通道会校验调用来源。
- 邮件正文里的图片不能指向本机或局域网地址，必须是真正的图片（不接受 SVG）。这项检查只看字面地址，不做 DNS 解析。

## 代码整理（不改变行为）

- 删除 75 条总被后加载样式覆盖、从未生效的 CSS 声明。删除前后在 14 个页面、10 个弹窗、两种窗口尺寸下逐项比对计算样式，7346 个值完全一致。
- 主进程里重复的辅助函数合并（本机地址判断、phix Profile 读写等）。保存 phix Profile 改为原子写入，避免 PHL Lite 或网页端读到写了一半的文件。
- 根目录与 `docs/` 重复的文档合并为一份。存储方式的说明已与实际一致：账号记忆、API Key、笔记与 AI 会话为明文保存。

## 验证

- `npm test`：983 项通过 982 项。唯一失败的一项需要另外检出 PHL Lite 仓库进行比对，与本次改动无关。
- 真实 Electron 自检通过，打包后的程序自检也通过。
- 已构建测试安装包 `release/PH-Launcher-1.0.15-Setup.exe`，不在仓库中。

## 发版前

- 修改 `package.json` 版本号（建议 1.0.16），再按发版流程打包、上传。现有的 1.0.15 安装包和标签不包含以上改动。
- 新图标的字形取自 Windows 自带字体 Sitka。如需避免字体授权问题，可换成 OFL 开源衬线体（如 Source Serif 4）：先用 fontTools 把新字体的 P、H、L 转成路径替换 `assets/icon.svg` 里的三段 `<path>`，再运行 `npm run icon` 生成 png、ico 和 logo。
