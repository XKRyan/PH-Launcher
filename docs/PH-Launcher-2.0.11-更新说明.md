# PH Launcher 2.0.11 更新说明

本次更新集中修复任务详情、任务提交入口和本地 AI 的思考模式，并把作者联系方式放到“关于软件”的最前面。

## 任务详情

- “任务要求”只显示真正的说明正文。课程名、截止日期、Summative / Coursework 等徽标，以及 Dropbox 等页面标签，不再被当成任务要求正文。
- 没有可读的说明正文时，界面明确显示“未读取到任务要求，请在原网页核对”，不再用页面元数据拼出一段看似正文的内容。
- 保留任务说明里的段落、列表、嵌套列表和列表项图片。

## 任务提交

- 识别到“Not Submitted / Pending”的 Dropbox 任务时，任务详情会提供应用内选择文件并确认上传的入口。
- 如果页面没有暴露可用的上传表单，仍提供“去原网页提交”按钮，避免把不可提交的任务说成已开放。
- 上传结果继续按“尚未核实”处理：程序不会自动重试，也不会替用户标记为已提交。

## 本地 AI

- 本地 Ollama 设置新增“思考模式”开关，可随时开启或关闭；此前请求固定为 `think: false`，界面无法调整。
- 开启后使用模型自己的 thinking 输出，并提高输出预算，避免思考把回答预算用完；关闭后保持原来的快速回答。
- 思考内容仍单独显示在“思考过程”块里，正文到达后自动收起，不与回答混在一起。
