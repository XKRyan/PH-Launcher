# PH Launcher 1.0.4

本次为 Windows 界面修复更新，保留 1.0.3 的功能与本地数据位置。

- 修复英文界面中的到期复习、新词数量、今日词数等动态提示仍显示中文的问题；补充日期、任务、学习进度和 AI 状态翻译。
- AI 输入区改为紧凑工具栏。快捷提问和附件说明可展开，文件、照片与记忆开关仍可使用。
- 输入框默认单行，随输入增高，到达上限后内部滚动，为聊天内容留出更多空间。
- 新建空会话的默认名称随语言切换；用户自己的会话标题、消息、课程、邮件和词义保持原文。

退出旧版后安装。安装包尚未数字签名；建议更新前导出备份。Mac 更新待 Windows 试用确认后制作。

本次未确认聊天记录消失的原因，也没有删除或重置用户聊天数据。
