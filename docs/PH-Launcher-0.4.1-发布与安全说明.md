# PH Launcher 0.4.1 发布与安全说明

## 本版修复

- 修复首次部署本地 AI 时，Ollama 大型安装包因网络波动中断后必须从头下载的问题。
- 安装包现在支持自动重试和跨点击断点续传；取消或暂时失败时会保留已下载部分，部署成功后自动清理缓存。
- 部署失败会直接显示具体原因，并保存不含账号、笔记或 API Key 的本地诊断日志。
- 增加“查看部署日志”和“浏览器下载安装”回退入口。
- 数字签名校验收紧为 Ollama Inc. 官方发布者；校验失败时不会运行安装包。
- 调整首次部署磁盘余量要求，为 Ollama 程序、临时安装包和模型同时预留空间。

## AI 操作安全边界

“AI 操作启动器”默认关闭。开启后，AI 可按授权读取任务、课程表、少量笔记摘要、今日概览、离线词典与 IB 指令词，并可提出新增任务、笔记或课程等更改。

所有数据写入先生成完整预览，用户确认后才保存；预览后数据发生变化时，旧确认会自动失效。PH Launcher 不向 AI 提供网站密码、Cookie、验证码、API Key、文件系统或任意网页脚本权限。AI 不能清除登录数据、删除资料、发送邮件或提交作业。

EduPage 只读取已经打开的“常规课表”中的课程名、星期、时间与教室。动态调课、停课和今日视图不会被当作固定课表导入，空结果也不会删除已有课程。

## 分发状态

- Windows x64 安装版与免安装版已完成启动、自检、离线词典随包、安装及卸载验证。
- Windows 文件目前没有商业代码签名证书，系统可能显示“未知发布者”；请通过可信渠道获取，并核对 SHA-256。
- `macOS-BuildKit` 是可在 Mac 上构建 Universal DMG／ZIP 的源码包，不是可双击安装的 Mac 成品。正式分发仍须在 macOS 上完成 Apple Developer ID 签名、公证与实机验证。
