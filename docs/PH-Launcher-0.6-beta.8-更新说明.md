# PH Launcher 0.6.0-beta.8

## AI 能读取学习内容，也记得对话

在 AI 学习助手左侧选择“完整权限”，阅读并确认新的数据范围。本次扩大了读取范围，升级用户也需要重新确认；原有学习数据不会因此清除。

- 按你的请求读取课程、成绩、作业、课表、日程、笔记、词汇和邮件。学校详情需要已有有效登录状态；过期时请在学校账号入口重新登录。
- 可以说“查看我邮箱中关于大学宣讲会的内容并写入日程”：先搜索和读取相关邮件，再显示待确认日程。核对日期、时间、地点与提醒后确认写入。缺少明确年份或时间时，应先补充，不能依赖 AI 猜测。
- 完整权限不等于无限制电脑访问。密码、Cookie、客户端授权码与邮件附件不会提供给 AI；代发邮件、代交作业和不经确认写入未开放。敏感邮件识别不能保证涵盖所有内容。
- API 模式会把本次获准读取的内容发送给所选服务商；本地模式在电脑上处理。普通聊天不会自动读取收件箱。
- 对话和手动添加的“长期记忆”保存在当前电脑，并用系统密钥加密。支持查看、删除会话及编辑记忆；最多保存 30 个会话，每个 120 条消息。更换连接后旧会话仅供查看，不会自动转发；API 默认不附加长期记忆。

## 背单词：先认识，再回忆

从“今日学习”选择难度和下一组推荐方式，再点“开始学新词”。先认识最多 5 个新词，再统一回忆；“我会这个词”可跳过。已有到期词时先复习，黄色数字显示到期数量。

- “用语境填空学”可直接选择填空模式；推荐的 60 词原创语境练习本全部带例句。有例句的词用于填空；其他词保留词义练习，不用无关句子冒充语境。
- 下一组推荐可选本地 AI、API 或关闭，默认本地。AI 根据候选词难度和最近的学习表现排序，可为所选词生成例句；它不保证最适合每个人，觉得简单仍可直接升档。
- API 推荐须另行同意，可能产生费用；不会把学校资料、阅读全文或聊天历史附带发送。AI 不可用时可以继续离线学习，不强制安装或下载模型。
- “我的词书”保留推荐入口：TOEFL、IELTS、CET、GRE、高频阅读等参考词本可一键从内置 ECDICT 分批加入，不需要再次下载，也不是官方考试词表。
- 阅读积累中用鼠标选中英文单词，即可离线查词并加入词汇列表，保留原句。重复收词不会重置原有复习进度。
- 学习过程始终保留返回入口；自己的表达可以保存，并可交给已配置的本地模型纠错。

## 课表与独立提醒

个人课表默认只显示周一至周五，需要时点“显示周末”。课程卡片有更大的空间，冲突课程集中展开查看。

- 我的课表 → 上课提醒：选择不提醒、准时或提前 5／10／15／30／60 分钟，仅作用于当前账号已选教学组。
- 我的日程 → 点击日期或日程：在该日程内单独设置提醒；全天事件不提醒，填写起止时间后即可开启。
- 专注结束、上课与日程提醒使用独立大窗口，提供“关闭”和“5 分钟后提醒”。删除日程或关闭对应提醒会撤回尚未处理的提醒。

提醒依赖程序仍在运行、电脑未休眠。学校课表提醒依赖当前账号成功同步；不能代替学校铃声。原“计划”中手动课程的已有提醒保持独立。

教学组可根据已读取的 ManageBac 课程提供唯一匹配建议，有歧义时仍需你确认，不能保证自动识别所有选课。全校空教室查询未开放：当前数据不足以证明某间教室没有其他班级使用。

## 更新与保留数据

先从托盘菜单完整退出旧版，再运行新版安装程序。正常更新同一系统用户的安装版会替换程序并保留用户目录中的设置、账号和学习记录；无需先卸载。建议先导出学习数据备份。密码不在导出备份中；AI 对话单独加密保存，不包含在学习数据 JSON 备份中，也不应把加密文件直接拷到另一台电脑。

免安装版须完整解压整个 ZIP，再打开其中的 `PH Launcher/PH Launcher.exe`，不要只复制 EXE。

本版为 Windows x64 本地测试包，未签名，尚未上传 GitHub，无对应新 Mac 安装包。功能回归使用测试数据和隔离用户目录；真实邮箱、真实模型回答及学校内容仍需用户核对，不能以测试通过保证所有账号和模型都正常。
