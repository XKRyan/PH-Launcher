# PH Launcher 1.0.7

本版相对于 0.5.1 是一次完整升级，Windows 与 macOS 共享同一套功能和数据结构。

- API 附件发送、删除任务/笔记/日程、清理登录数据和恢复备份等确认框，统一使用应用内主题样式。
- 取消原生阻塞式确认框调用，减少焦点与指针异常；弹窗和背景明确使用可见鼠标样式，关闭后恢复焦点。间歇性系统鼠标问题仍需实际电脑复测。
- 默认聚焦取消，支持 Esc、关闭按钮；取消不会发送或删除。
- API 发送确认期间若模型、服务商、会话、消息或附件发生变化，本次发送会取消，需重新确认。

- 修正 AI 多轮操作共用两分钟时限的问题，改为每轮独立计时，并区分 API 与本地模型超时提示；不会自动重试。

应用内弹窗布局与焦点检查通过。安装包未数字签名，退出旧版后安装。

## AI 助手升级（对齐 Pinghe Launcher Lite）

- **流式输出**：本地与 API 模型都逐步显示回复；开启流式后仍可使用工具，写入依旧逐条确认。
- **工作区**：在 AI 面板选择或新建一个文件夹，AI 可以列出、读取其中的文本与 Word 文档，并起草 Word 文档。所有路径必须落在该文件夹内，绝对路径、`..`、符号链接和 `.git` 都会被拒绝；未选择文件夹时文件工具不可用。
- **待确认的外发操作**：发送邮件、提交 ManageBac 作业、回复讨论。没有在清单上确认就不会执行；确认后邮件还会再弹出一次系统确认，提交作业只允许上传工作区内的文件，提交与回复都会提示你到学校网站核对。这些操作只在"完整权限"下提供。
- **DDL 查询**：可按未来 N 天（默认 14 天）列出已同步的 ManageBac 作业，并标出是否已提交。
- 权限说明、确认卡文案与帮助文档同步更新：确认卡会区分"保存到 PH Launcher"和"确认执行"，不再把外发操作说成仅保存本地。

## 数据结构与 Hello Pinghe! Launcher 对齐

- 数据根目录按 `PHL_DATA_DIR` → 记录的共用目录 → 便携 `portable.flag` → 本应用默认目录的顺序解析。两个程序装在同一文件夹并使用便携模式时会自动共用同一个 `data/`；其他情况可在「设置 → 数据与隐私」点"改用 Lite 的数据目录"并重启生效。
- 共用文件：`settings.yaml`（账号与配置）、`Schedule`（按天日程）、`agent/`（AI 会话记录）。本应用的私有数据放在 `phl/`，Lite 的私有数据在 `phll/`，互不读写。
- 账号可在「设置 → 网站 → 账号记忆」里两个方向显式共用；`settings.yaml` 是明文文件，写入方向会再确认一次。
- 旧版数据以**只复制不删除**的方式迁移到 `phl/`，并记录在 `phl/migrated.json`；源文件保持原样，可随时回退旧版本。
- 详细字段、合并规则与安全边界见 [数据格式规范](data-format.md)。
