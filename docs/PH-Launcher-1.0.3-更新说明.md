# PH Launcher 1.0.3 · Windows 测试版

本次沿用 1.0 系列，继续完善背单词、日程和 AI 体验。先提供 Windows 版；Mac 更新待 Windows 试用确认后制作。

- 背单词的推荐、例句翻译、填空分析和造句纠错统一选择本地 AI / API / Offline。明确区分所选方式与实际离线状态；API 模式不再误显示本地加载提示。
- 新词先理解再回忆；五个不会的词组成一组，会的词跳过补位，回忆顺序打乱。学习时预准备至多下一组，减少组间等待；网络或模型较慢时仍可立即离线开始。
- 例句可展开中文翻译，划选陌生词可用离线词典查义并保留原句收入生词本。AI 可解释拼写、词形与近义词差异，不自动更改复习评分。
- 新加入且没有例句的词，在所选 AI 可用并获得授权时后台补例句。单次最多排队 40 词，每批 5 词；更多词留待后续学习组处理。不覆盖已有例句，失败不反复请求。AI 例句与反馈需要自行核对。
- 日程可选择周一至周日每周重复，从起始日期开始；提醒可完成本次、延后 5 分钟或取消本次，不删除未来系列。支持关联本地文件，只保存文件位置，不自动上传；文件移动后需重新关联。
- AI 对话新增文件和照片附件。文档支持 TXT、MD、DOCX、PDF，照片支持 JPG、PNG、WebP。每类最多 3 个，单个 10 MB、合计 20 MB；文档发送节选，照片需要支持视觉的模型。仅本次发送附件内容，聊天历史保留文件名；后续要继续分析文件请重新添加。
- 补齐页面、弹窗、提示和原生菜单的中英文切换；保留用户笔记、邮件、学习材料原文。托盘菜单移除旧网站入口。
- IB 工具页新增 TOEFL / IELTS / SAT / ACT 资料分类，提供 ETS、IELTS、College Board、Bluebook、Khan Academy、ACT 等资料入口。请核对考试版本与资料日期；部分内容可能需要账号或付费。

## 使用与隐私

使用 API 前需确认词汇推荐、后台例句和纠错涉及的数据范围，可能产生费用；照片和文档会在发送前再次确认。选择本地 AI 时仅启动已安装且配置的本机服务，不自动改用 API，也不会自动下载新模型。关闭 AI 后仍可离线学习。

升级前完全退出旧版，建议在设置中先导出备份。同一 Windows 用户正常升级保留原数据，不要删除用户数据目录。本版仍未数字签名。
