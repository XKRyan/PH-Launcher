# PH Launcher 使用指南

PH Launcher 是面向平和 IB 学生的独立 Windows 与 macOS 学习工作台。它把学校邮箱、ManageBac、EduPage、计划、笔记、课程提醒、专注计时、IB 小工具和可选 AI 放在一个安静、统一的界面中。

> PH Launcher 不是上海市民办平和学校、ManageBac、EduPage 或网易的官方产品，也不使用校徽。网站名称与服务归各自权利人所有。

## 开始使用

1. Windows 日常使用建议双击 `PH-Launcher-0.4.1-x64.exe` 安装；若不想安装，则运行 `PH-Launcher-0.4.1-Portable.exe`。
2. Mac 正式分享版采用 Universal DMG，可运行在 Apple 芯片与 Intel Mac 上。如果你拿到的是 `macOS-BuildKit` 或“未签名测试版”，它还不是可直接分发的成品；必须先在 Mac 上完成构建、Apple Developer ID 签名、公证与实机验证。
3. 如果 Windows SmartScreen 提示“未知发布者”，请先确认文件来源与校验值，再选择“更多信息 → 仍要运行”。Windows 版目前未购买代码签名证书。
4. 在左侧打开学校邮箱、ManageBac 或 EduPage，并使用你自己的账号登录。

三个网站各自使用独立登录空间。PH Launcher 不读取或保存网站密码；登录信息由网站与系统浏览器组件管理。

## 简洁显示模式

“简洁显示”会整理已确认学校页面的背景、卡片、表单、间距和配色，并收起部分与登录无关的展示内容。它不绕过网站安全策略，也不修改账号、数据或业务逻辑。顶部显示“已应用”才代表当前页面确实启用了简洁样式；不支持的页面会自动保留原网页。网站更新后如果某页显示异常，可立即关闭开关并刷新。

设置中的“清除登录数据”会清除对应网站的 Cookie、缓存与登录状态，不影响 PH Launcher 里的笔记和任务。

## 学习工具

- 计划：建立任务、截止时间、科目、优先级与预计用时。
- 课程表：按星期添加课程、教室和提前提醒时间。提醒要求 PH Launcher 正在运行或停留在系统托盘；如需每天自动提醒，可在设置中开启开机启动。
- 专注计时：提供 25/5、45/10、50/10 和正计时模式，并记录每周专注时间。
- 笔记：自动保存，支持搜索、科目、置顶，并可把笔记转为任务。
- 离线英汉词典：内置 770,611 个本地词条，支持音标、中英文释义、词形变化、宽松匹配、系统语音朗读及保存到笔记；查询内容不会联网发送。词库来自 MIT 许可的 [ECDICT](https://github.com/skywind3000/ECDICT)。
- IB 工具：“IB 指令词速查”解释 Analyze、Evaluate、Discuss 等题目动词要求的答题动作与深度；它不是 AI 指令。另含中英文写作统计、加权成绩计算，以及 EE、TOK、IA 里程碑模板。

## 快捷键

窗口内默认可用；Mac 请把下列 `Ctrl` 换成 `⌘`：

- `Ctrl+1 / 2 / 3`：学校邮箱 / ManageBac / EduPage
- `Ctrl+K`：命令面板
- `Ctrl+D`：离线词典
- `Ctrl+Shift+N`：新建笔记
- `Ctrl+Shift+A`：新建任务
- `Ctrl+Shift+P`：开始或暂停专注
- `Ctrl+,`：设置

Windows 默认全局快捷键为 `Ctrl+Alt+Space`，Mac 为 `⌘+Shift+Space`，用于显示或隐藏 PH Launcher。其他全局快捷键可在设置中按需开启、修改；若组合键已被其他软件占用，PH Launcher 会给出提示。

## 可选 AI

AI 默认关闭。关闭时，三个学校网站入口和全部本地工具仍可完整使用，也不会下载模型或连接 AI 服务。

### 本地 AI

每台电脑进入“AI 学习助手 → 本地 AI”时，PH Launcher 都会重新读取本机处理器、内存、显卡显存和系统盘可用空间，再给出该电脑自己的建议。更换电脑后不会沿用另一台电脑的推荐。

在 Windows 点击“一键部署推荐模型”后，PH Launcher 会查找已有 Ollama；如未安装，则从 [Ollama 官方网站](https://ollama.com/download/windows)下载安装程序并验证 Windows 数字签名；随后启动本地服务、下载推荐模型、验证并自动启用。页面会显示进度，下载过程中可以取消。Ollama 官方安装包较大，PH Launcher 会自动重试并保留下载断点；网络中断后再次点击“继续部署”不会从零开始。失败原因会直接显示，同时保存在本地部署日志中。

Apple 芯片 Mac 会根据统一内存与磁盘空间给出保守建议。Intel Mac 默认不推荐本地 AI，因为只能使用 CPU，延迟与发热通常较高。Mac 未安装 Ollama 时，PH Launcher 会打开[官方 Mac 安装页](https://ollama.com/download/mac)，安装需由用户本人完成；安装并启动后返回页面继续部署。macOS 13 可以运行 PH Launcher，但当前 Ollama 需要 macOS 14 或更高版本。

一键部署只允许下列经过应用审核的模型名称，不接受网页或输入框拼接安装命令：

- 低配且内存至少 8 GB：Qwen3.5 0.8B
- 约 12 GB 内存：Qwen3.5 2B
- 约 20 GB 内存，或至少 16 GB 内存配合 6 GB 级显存：Qwen3.5 4B
- 32 GB 内存、8 GB 级显存且磁盘充足：优先 4B，可自行尝试 9B

这是保守的流畅度建议，不是性能保证；后台程序、散热和显卡共享内存都会影响速度。磁盘不足 6 GB 或内存不足 8 GB 时，PH Launcher 会建议不要进行一键部署。模型文件会占用数 GB 空间，具体大小和下载时间会在页面显示。

不希望由 PH Launcher 自动安装时，可展开“手动连接已有 Ollama（高级）”，自行填写本机地址和已经安装的模型名称。自动部署与手动模式都只连接 `127.0.0.1` 上的本地服务。

### API AI

API 模式支持兼容 OpenAI Chat Completions 的 HTTPS 服务。普通对话只发送你主动提交的文字；如果另外开启“AI 操作启动器”，AI 请求读取的任务、课程表或笔记摘要也会发送给你配置的服务商。风险提示会在开启前单独说明。API Key 保存在当前系统用户的加密本地数据中，导出的备份不包含 Key。

请不要把学校账号密码、验证码、他人的个人信息或不应上传的作业材料发送给任何云端 AI。

### AI 操作启动器

AI 连接启用后，还可以单独打开“AI 操作启动器”。此权限默认关闭，开启前必须阅读并确认风险提示。

开启后，AI 可以读取经授权的任务、常规课程表、少量笔记摘要、今日概览、离线词典和 IB 指令词，也可以打开启动器页面或控制专注计时。它可以提出添加任务、创建笔记、合并课程和修改任务完成状态，但不会直接写入；每批更改都会显示完整清单，只有用户确认后才保存。

AI 不会获得密码、Cookie、验证码、API Key、文件系统或任意网页脚本权限，也不能清除登录数据、删除资料、发送邮件或提交作业。AI 仍可能误解内容，确认前必须核对课程、星期、时间、教室和截止日期。

“从 EduPage 读取常规课表”使用固定的本地只读提取器，只读取课程名、星期、时间和教室。请先在 EduPage 打开“常规课表”，再回到 AI 页面生成预览。PH Launcher 会拒绝把“今日／本周动态课表”中的临时调课、停课或活动导入为每周固定课程；导入只合并，不会因为识别为空而删除原课程。

## 数据与备份

笔记、任务、课程表、专注记录、设置和 API Key 默认保存在当前系统用户目录，并使用系统可用的本地加密能力；Mac 使用钥匙串保护。可在“设置 → 数据与隐私”查看准确位置。

“导出备份”生成可迁移的 JSON 文件，不包含 API Key，也不会额外加密。请妥善保管；“恢复备份”会替换当前的本地数据。

## 常见问题

- 网页空白或排版异常：先关闭“简洁显示”，再刷新；仍有问题时使用“在浏览器中打开”。
- 登录循环：清除该网站登录数据后重新登录。清除前确认自己记得账号与密码。
- 没有课程提醒：确认应用仍在运行或系统托盘／菜单栏中，并检查系统通知权限。
- 本地 AI 无法连接：确认 Ollama 正在运行，并且页面里的模型名称已经安装。
- API 无法连接：核对 HTTPS 地址、模型名称、余额和 Key；不同服务商的兼容程度可能不同。
- EduPage 课表无法识别：确认已经登录并打开“常规课表”，让课程名与具体时间显示在页面上；不要停留在今日动态视图。

学校网站登录后的页面会因账号权限而不同。首次分发给同学前，建议由一名真实学生账号分别验证邮件收发、ManageBac 文件下载和 EduPage 常用功能。
