# PH Launcher 0.6.0-beta.7

## 邮件按钮与链接

邮件正文前新增“邮件中的链接”，保留邮件按钮的文字并显示实际域名。图片形式的按钮也能显示链接，不需要加载远程图片。点击后先核对域名，再确认交给系统浏览器打开。

请核对发件人与链接去向。链接可以打开不代表网站可信；密码重置和登录操作请在确认无误的官方网站完成。

## AI 完整权限

在 AI 对话左侧选择“完整权限”，分别确认启动器操作风险和邮件读取风险，即可让助手查询收件箱、读取指定邮件和查找已读取邮件中的联系人。

- 只在你提出邮件相关请求后读取，不自动上传整个收件箱。
- API 模式会把被允许读取的内容发送给你配置的服务商；本地模式交给本机模型。
- 邮件中的文字不是操作授权。附件、凭据库和登录 Cookie 不提供给模型；识别为密码重置、验证码、登录通知的邮件会拦截正文，提醒你到邮箱查看。自动识别不能保证覆盖所有敏感内容。
- 写入任务、笔记等仍须确认。完整权限不包含无限制电脑访问、代发邮件或代交作业。
- 更换模型或连接后须重新确认邮件权限；随时可以切回普通对话。

## 本地 AI 随所选模式准备

选择本地 AI 时，启动 PH Launcher 就会后台准备已安装的服务与选中模型；选择 API Key 或暂不启用时，不会启动本地 AI。不会因此后台下载模型或安装软件，也不会结束其他软件可能使用的 Ollama 服务。首次加载仍需要一些时间，但不会挡住主界面打开。

## 语境填空仍然保留

新词先认识一组，再统一回忆。在练习方式中选择“语境填空”，也可在学习设置中设为默认。没有例句的词暂用词义回忆；为词添加包含目标词的例句后即可使用语境填空。

## 更新

先从系统托盘菜单退出旧版，再打开新版。免安装 ZIP 必须完整解压，配套文件须留在一起，不要只复制 EXE。原有学习数据不会随更新清除。

这是 Windows 本地测试包，尚未上传 GitHub，也没有对应的新 Mac 安装包。Windows 包未签名，请核对来源和 SHA-256。邮件链接及 AI 权限使用测试邮件验证，尚未完成真实邮箱与模型的端到端验证。学校内容仍以官方记录为准。
