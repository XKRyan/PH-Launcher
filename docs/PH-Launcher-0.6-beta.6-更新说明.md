# PH Launcher 0.6.0-beta.6

## 更一致的界面

六套主题现在也会影响顶部中间背景和 Windows 右侧窗口按钮，重启后保持选择。修复了系统托盘图标为空的问题。

默认字号调整为 16px，设置中可选 14–24px；以前手动设置的字号不会被覆盖。弹窗统一了内边距、关闭按钮和底部按钮位置，放大字号时可滚动查看内容。计划和背单词的黄色数量提示保持居中。

设置中新增简体中文／English 切换。个人内容、学校信息、学习材料和 AI 回复不会被翻译。

## 背单词：先认识一组，再回忆

- 今日学习、我的词书、更多工具三个入口分工更清楚；阅读积累收在“更多工具”中。
- 新词顺序打乱，每组最多 5 个；先看完词义和例句，再开始这一组的回忆。
- “我会这个词”可跳过已会词；以后可在已暂停词条中恢复，不会制造虚假的复习成绩。
- 到期词仍按复习时间安排，侧栏黄色数字提醒待复习数量。
- 自己的表达有独立的保存入口，也可交给已经启用的本地 AI 纠错。建议不会自动覆盖原句，采用后仍需保存；AI 结果请自行核对。

## 专注有目标，也方便暂停

在侧栏点击“调整时长与目标”，可设置 1–180 分钟、填写目标并选择要打开的学习页面或自选网站。开始或继续时打开目标；暂停、继续和结束按钮在侧栏即可找到。提前结束不会记录为完成，运行中调整时长从下一轮生效。

## 本地 AI 的回复看得见

普通本地聊天逐步显示文字，并提供停止按钮。已启用的本地模型会在程序启动后尝试后台预热：只使用已运行的 Ollama 和已安装模型，不会自动下载模型或启动服务。模型仍会占用内存，首次准备与生成速度取决于电脑、模型及后台负载。

连接设置顶部新增“返回对话”，不再需要展开高级连接选项才能回到聊天。未配置模型时可直接返回首页。表达纠错只向本机模型发送当前词和句子。

## 更新与使用边界

先从系统托盘菜单退出旧版，再打开新版。Windows 提供安装版与 Folder ZIP；免安装包须完整解压，不要从压缩包内直接运行，也不要只复制 EXE。已有学习数据不随更新清除。

本版为 Windows 本地测试包，尚未上传 GitHub，也没有对应的新 Mac 安装包。Windows 包未签名，下载后请核对来源与同目录校验值。

学校内容仍以官方记录为准。真实邮箱收发、Discussion 的真实账号页面仍待进一步验证；邮箱目前只提供收件箱，不含已发送／草稿目录。AI 不会代发邮件或代交作业，写入启动器的更改仍须确认。API 聊天及需要工具的操作回合暂不逐字显示。
