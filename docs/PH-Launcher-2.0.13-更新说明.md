# PH Launcher 2.0.13 更新说明

发布日期：2026-11-09

这一版把自动更新改成“后台静默处理”，尽量不打扰正在用软件的人。

## 更新过程不再打扰

- 每次启动后，软件会在后台**静默检查**更新；发现新版本就**静默下载**。
  检查与下载期间没有系统通知、没有弹窗、没有进度提示，可以照常使用。
- 启动时如果已有更新（正在下载 / 已下载 / 下载失败），会弹出更新卡片；
  在「设置 → 关于软件 → 检查更新」手动检查时也会弹出同一张卡片。
- 卡片上会显示**下载进度条**：
  - 还没下完：显示当前百分比，下载在后台继续；
  - 下载完成：按钮变为「重启并安装」；
  - 下载失败：显示原因，可点「重试下载」。
- 点「取消」只会关掉卡片，后台下载继续进行；下次启动或手动检查还会提示。
- 点「跳过本版本」后，这个版本不再提示；更高的新版本仍会提示。
- 安装仍由你决定：只有点「重启并安装」才会退出并安装，**绝不会自动安装**。
- 已下载的更新会被复用，下次启动不会重复下载同一个版本。

## 说明

- 更新包仍会做 SHA-256 校验；下载失败会如实显示，不会假装已是最新版本。
- Windows 安装包未签名；macOS 为 ad-hoc 临时签名、未公证，首次打开可能需要在
  「隐私与安全性」中允许。
- 本版本没有改动账号、同步、课表、作业等数据；个人数据不会因为更新而丢失。
