# PH Launcher 0.6 协作预览说明

此文记录 `0.6.0-beta.5` 的功能边界；后续改动见 [beta.7 更新说明](PH-Launcher-0.6-beta.7-更新说明.md) 与 [当前使用指南](../使用指南.md)。

PH Launcher × [Hello Pinghe! Launcher](https://github.com/huaziqian40-bot/Hello-Pinghe-Launcher) 是一次学生工具项目的合作整合。本版继续以 [XKRyan/PH-Launcher](https://github.com/XKRyan/PH-Launcher) 为应用主体，并整合受 GPL-3.0-or-later 约束的学校认证适配代码。感谢 XKRyan、huaziqian40-bot 与双方贡献者。

组合发行版采用 GPL-3.0-or-later；原 PH Launcher 的 MIT 条款保留在 `LICENSE-MIT-PH-Launcher.txt`。学校认证适配层保留 Hello Pinghe! Launcher 与 edupage-api 的来源和版权声明，但没有捆绑 Python 运行时、wheel 或 Python 依赖。只移植了本版所需的受限登录流程；Hello Pinghe! Launcher 的其余功能并未全部整合。详见[学校数据整合说明](school-integration.md)。

## 0.6.0-beta.4 变化

- 左侧学校应用为“我的课表、我的日程、班级课表、我的课程、平和邮箱”五个入口。ManageBac 与 EduPage 可在账号框中输入凭据、确认风险后直接“保存并登录”，无需先打开原网页登录。
- 我的课表按个人教学组筛选；班级课表独立展示当前账号所属班级的全部可见教学组。课程、作业与截止、CAS／EE 统一放在“我的课程”中。
- 平和邮箱改为本地收件箱：显示最近 100 封邮件、全部／未读筛选、纯文本正文、附件保存、从已读取邮件头补全联系人与写邮件。发送前始终由系统确认。

## 0.6.0-beta.5 变化

- 已保存的学校或邮箱账号可在启动后后台同步；未保存账号不会因此发起连接，学校的自动重新登录仍默认关闭。
- “我的课表”在尚未选择个人教学组时给出明确引导；时间相同或相近的课程会聚合显示，减少拥挤时的遮挡。
- ManageBac 增加只读的 Discussion 列表、正文和已有回复查看，不会向学校网站发布内容。
- 平和邮箱会把附件放在正文前，并在邮件列表标明附档。该交互目前只以测试邮件数据核对，真实授权码邮箱的收发仍待验证。
- 背单词的新词先显示词义；有例句时展示完整语境，再由学习者选择是否开始回忆。ECDICT 可选五类词本，支持离线分批导入。
- 可选自评、IELTS、TOEFL 旧／新分制或 8 道题，用于获得粗略起点建议；这不是标准化测验，也没有接入 AI 推荐。
- 全局字号默认 18px，可调整为 14–24px；AI 页面左侧展示现有权限，右侧提供临时会话聊天。
- “简洁显示”已废弃，学校网站继续保留原网页显示。

## 已有的登录与更新功能

- “保存并登录”只完成用户主动发起的这一次登录。ManageBac 与 EduPage 的“自动重新登录”仍是单独明确开启的选项，默认关闭；验证码、双重验证和未知页面仍要求在原网页手动完成。
- 学校页面可选择自动刷新，默认关闭；开启后只在页面可见且内容过期时检查。学校结果只在本次运行的内存中保留。
- 启动后台同步只面向已保存账号，不会强制提交账号密码或打开未保存账号的连接。

## 本次可以使用的功能

### 背单词与本地阅读

- 使用 FSRS 6 在本机安排复习；内置原创 36 词入门包，也可添加自己的词和语境。
- 支持看语境回忆、看词回忆与拼写练习，并可撤销一次评分、暂停词条。
- 可粘贴自己有权使用的英文材料，从原句查词、标记生词并收藏上下文。文章、上下文、复习记录和阅读记录均保存在本机。
- “每天半页”是开始阅读的建议，不是硬性目标。阅读词次和用时只在本人点击确认读完后记入统计，不代表理解程度或词汇量。
- 词本与阅读数据支持导入、导出；导出的文件需由用户自行妥善保管。

视频方法部分依据用户提供的内容摘要，不是完整字幕或逐字转写。背景、证据边界与独立研究见[语境背词研究说明](vocabulary-research.md)。

### 课表与课程

“我的课表”“班级课表”和“我的课程”只读读取 ManageBac／EduPage 数据，不会向学校网站提交学习数据修改。用户可在账号框中保存并登录；默认不使用保存的密码恢复后续登录，只有明确开启自动重新登录时才会在登录失效的受限读取流程中使用系统保护的凭据。

- EduPage：按明确日期显示七日课表，保留老师、教室、停课和未覆盖日期；选择自己的教学组后，可预览并导入到本地计划。授权登录与整周课表读取已经完成一次真实授权验证；不会记录或展示账号、密码或课程内容。
- ManageBac：显示课程、语义明确的课程总评、作业卡片及详情、课程单元、课程文件名称和课程日历，并提供 CAS／EE 摘要入口。真实授权登录与课程列表读取已经完成验证；这不代表所有课程详情、成绩或作业页面均已完成真实验证。
- 所有学校数据都应以原网页和学校官方记录为准；登录过期、页面改版或数据不完整时，请回到原网页核对。

除上述 EduPage 与 ManageBac 验证外，学校读取器仍需针对不同账号、班级和页面持续核对，不能承诺所有情形都正确读取。详细边界见[学校数据整合说明](school-integration.md)。

### 平和邮箱

平和邮箱显示最近 100 封邮件，可筛选全部或未读邮件；正文以纯文本显示，不加载外部图片。附件会列在正文前，邮件列表也会显示附档标识；你可以保存附件、从本账号已读取邮件头中选择联系人，并写邮件。每次发送前都会显示系统确认。

网易邮箱可能需要客户端授权码；网页密码本身可能不足以连接。附件显示与保存流程目前仅以测试邮件数据核对，真实收发尚未完成验证，不能把它当作已验证的收信或发信功能。暂不支持发送附件、自动标记已读或由 AI 代发。

### 我的日程与外观

- “我的日程”提供周、月、年视图，可按日期新增或编辑本地日程。日程事件目前没有提醒通知；原有每周课程表的课前提醒不受影响。
- 提供六套主题、四种角色配色；全局字号默认 18px，可在 14–24px 间调整。

### AI 页面

AI 页面左侧说明当前可用权限，右侧提供本次运行内的临时聊天会话。现有只有普通对话与须用户确认的操作两种权限：没有完全访问权限，聊天会话也不会在应用重启后保留。

### 可选账号记忆

账号记忆默认不保存任何密码。用户主动同意后，PH Launcher 会使用当前系统用户的系统密钥加密保存学校账号。ManageBac 与 EduPage 仅用于对应学校站点；平和邮箱凭据仅用于网易固定邮件服务器，并且自动填入默认关闭。

保存的密码只留在当前电脑，不写入导出备份，不提供给 AI，不显示明文，也不支持任意网站。ManageBac 与 EduPage 的自动重新登录须在设置中另行明确开启，且仅在读取操作登录失效后按受限流程尝试一次。它不会处理验证码或绕过双重验证。共享电脑不建议启用；任何能解锁当前系统账户的人都可能使用已保存的凭据。

## 本版尚未实现

以下功能仍未完成或未完成最终验证，不属于 `0.6.0-beta.5`：

- 网易邮箱的真实收发验证；
- 邮件附件发送、自动标记已读、AI 代发邮件或代交作业；
- Word 文档起草；
- 任意班级或非当前账号范围的查询；
- AI 的完全访问权限或跨重启保留的会话。

ManageBac 和 EduPage 的原生网页仍可照常使用；“未实现”不等于原网站功能被移除。

## 下载与发布状态

本地验证中，241 项单元测试及 Electron 27 项自检均通过；24px 字号下关闭按钮保持 48×48 且居中。Windows 本地测试包采用安装版与 Folder ZIP，Folder ZIP 须完整解压后运行，不是 Portable 自解压程序。beta.5 不提供 Mac 安装包，也尚未上传 GitHub；远程可下载版本、文件名、签名与校验值以实际 Releases 页面为准。

PH Launcher 不是上海市民办平和学校、ManageBac、EduPage、网易或 IBO 的官方产品，也不使用校徽。

## 版本沿革

0.6 在 0.5 系列既有的学校网页入口、自选网站、计划、笔记、专注、离线词典、IB 工具与可选 AI 基础上增加上述协作预览功能。旧版本的发布与安全说明继续保留，供已安装对应版本的用户查阅。
