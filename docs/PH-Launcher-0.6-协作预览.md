# PH Launcher 0.6 协作预览说明

当前版本：`0.6.0-beta.1`

PH Launcher × [Hello Pinghe! Launcher](https://github.com/huaziqian40-bot/Hello-Pinghe-Launcher) 是一次学生工具项目的合作整合。本版继续以 [XKRyan/PH-Launcher](https://github.com/XKRyan/PH-Launcher) 为应用主体，并结合 huaziqian40-bot 在 Hello Pinghe! Launcher 中的设计与学校数据接口经验。感谢 XKRyan、huaziqian40-bot 与双方贡献者。

这是设计与接口层面的合作整合，不表示 Hello Pinghe! Launcher 的连接器代码被复制到本仓库，也不表示其全部功能已经移植。原项目中的 GPL Python 代码未随 PH Launcher 打包。

## 本次可以使用的功能

### 语境背词与本地阅读

- 使用 FSRS 6 在本机安排复习；内置原创 36 词入门包，也可添加自己的词和语境。
- 支持看语境回忆、看词回忆与拼写练习，并可撤销一次评分、暂停词条。
- 可粘贴自己有权使用的英文材料，从原句查词、标记生词并收藏上下文。文章、上下文、复习记录和阅读记录均保存在本机。
- “每天半页”是开始阅读的建议，不是硬性目标。阅读词次和用时只在本人点击确认读完后记入统计，不代表理解程度或词汇量。
- 词本与阅读数据支持导入、导出；导出的文件需由用户自行妥善保管。

视频方法部分依据用户提供的内容摘要，不是完整字幕或逐字转写。背景、证据边界与独立研究见[语境背词研究说明](vocabulary-research.md)。

### 我的学校

“我的学校”使用当前电脑上已经登录的 ManageBac／EduPage 会话进行只读读取，不接收密码，也不会向学校网站提交修改。

- EduPage：按明确日期显示七日课表，保留老师、教室、停课和未覆盖日期；选择自己的教学组后，可预览并导入到本地计划。导入的是具体日期日程，不会冒充每周循环课程。
- ManageBac：显示课程、语义明确的课程总评、作业卡片及详情、课程单元、课程文件名称和课程日历，并提供 CAS／EE 摘要入口。
- 所有学校数据都应以原网页和学校官方记录为准；登录过期、页面改版或数据不完整时，请回到原网页核对。

学校读取器已经通过自造 HTML／JSON 夹具测试，但截至 `0.6.0-beta.1`，尚未使用真实已登录学生账号完成端到端验证。因此不能承诺每个账号、班级或页面都能正确读取。详细边界见[学校数据整合说明](school-integration.md)。

### 我的日程与外观

- “我的日程”提供周、月、年视图，可按日期新增或编辑本地日程。日程事件目前没有提醒通知；原有每周课程表的课前提醒不受影响。
- 提供六套主题、四种角色配色和学习内容页面缩放。

### 可选账号记忆

账号记忆默认不保存任何密码。用户主动同意后，PH Launcher 可用 Electron `safeStorage` 和当前系统用户的系统密钥加密保存学校账号，并仅在三个固定学校站点的登录页填入：`mail.shphschool.com`、`shph.managebac.cn`、`pingheschool.edupage.org`。

保存的密码只留在当前电脑，不写入导出备份，不提供给 AI，不显示明文，也不支持任意网站。自动填入绝不会自动点击登录、处理验证码或绕过双重验证。共享电脑不建议启用；任何能解锁当前系统账户的人都可能使用已保存的自动填入。

## 本版尚未实现

以下整合功能仍待完成，不属于 `0.6.0-beta.1`：

- 独立的 IMAP 邮件客户端与通讯录；
- AI 代发邮件或代交作业；
- Word 文档起草；
- 任意班级或非当前账号范围的查询；
- Hello Pinghe! Launcher 设想的四种新代理权限模式。

学校邮箱、ManageBac 和 EduPage 的原生网页仍可照常使用；“未整合”不等于原网站功能被移除。

## 下载与发布状态

`0.6.0-beta.1` 是协作预览版本。请只从项目 GitHub Releases 页面选择实际存在的发布和附件，并核对发布页提供的校验值。本文不表示 Mac 安装包已经构建，也不表示测试版已经上传；可下载平台、文件名、签名与公证状态，以实际发布页为准。
