# PH Launcher 1.0.8 修复版

以同学最新的学校集成分支为基础，保留新增的 AI 流式回复、思考过程显示、Markdown 排版和服务商选择保持功能。

本次修复：

- 取消选课后，不再因同步或重新打开选择界面而恢复原选项；支持取消全部选课。
- 课表红色时间线按上海时间和实际课程格子位置显示，窗口缩放后仍能对齐。
- 邮件已读状态以服务器确认结果为准，快速切换邮件或刷新时不再错误恢复未读。
- 修复日志输出连接断开时出现的 EPIPE 主进程错误。
- 修复部分 AI 模型兼容重试时可能中断的问题。

## 安装

退出旧版后运行安装包，沿用原安装位置。请勿先删除用户数据。此修复版沿用同学源码中的版本号 1.0.8，与此前独立构建的 1.10.1 不是按数字顺序迭代的关系。

之前已被旧同步逻辑恢复的课程，需要重新取消一次选择。
