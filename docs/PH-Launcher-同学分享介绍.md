# PH Launcher

PH Launcher 是为平和 IB 学生设计的一站式桌面学习工作台，由 PH Launcher（XKRyan）与 Hello Pinghe! Launcher（huaziqian40-bot）协作整合。

## 主要功能

- 平和邮箱、ManageBac、EduPage：统一入口、保持登录、读取课程与学习信息。
- 我的课表、我的课程、我的日程：周/月/年视图、每周固定日程、提前提醒与大窗口提醒。
- 任务、笔记、专注计时、六套主题、字号调节和中英文界面。
- 背单词：TOEFL、IELTS、SAT、GRE、CET 与高频阅读词书，先理解后回忆、错词分组、语境填空、例句翻译、阅读划词查词；AI 推荐与纠错可选。侧栏可直接打开本机的 VLMReader 阅读器。
- IB 工具：按学科查询指令词、写作字数统计、成绩计算、EE／TOK／IA 模板、官方资料与 IB Docs 入口。
- AI 学习助手：可选本地 AI 或 API AI；完整权限下可在确认后读取和整理启动器中的课程、日程、任务、笔记、词汇与邮件，所有写入先预览。
- phix 统一账号：可选的端到端加密云同步，与 PHL Lite、网页端共用同一套账号。
- 可添加自己的学习网站，并支持文件、照片、阅读材料和本地离线词典。

## 隐私与安全

密码、Cookie、验证码和 API Key 不会提供给 AI。账号记忆、日程、任务、词汇与对话保存在本机数据目录，当前版本未加密，共享电脑不要保存密码；开启 phix 云同步后，上传前会端到端加密，服务器只存密文。云端 AI 只接收你主动提交或明确授权的内容。PH Launcher 不是学校、ManageBac、EduPage、网易、IBO 或 Ollama 的官方产品。
