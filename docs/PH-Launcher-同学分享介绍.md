# PH Launcher

PH Launcher 是为平和 IB 学生日常学习设计的一站式桌面工作台。它把学校邮箱、ManageBac、EduPage 和常用学习工具放进同一个安静、统一的界面，让查看通知、安排课程、记录任务和专注学习少一些来回切换。

`0.6.0-beta.1` 是 PH Launcher（XKRyan）× Hello Pinghe! Launcher（huaziqian40-bot）的协作预览：以 PH Launcher 为主体，结合双方在界面设计与学校数据接口上的经验，并保留双方署名。

## 它能做什么

- 在一个应用内打开学校邮箱、ManageBac 与 EduPage，并使用彼此隔离的登录空间；具体保持时间由各网站决定。
- “简洁显示”默认关闭；需要时可按学校网站开启，顶部会明确显示是否已应用，遇到不兼容页面可随时恢复原网页。
- 可以添加最多 12 个自己常用的 HTTPS 学习网站；每个网站独立保存登录，并可设置颜色、顺序和全局快捷键。
- 集成任务清单、课程表、上课提醒、笔记、专注计时和每周专注统计。
- 新增周、月、年日程，以及六套主题、四种角色配色和学习内容缩放；日程事件暂时没有提醒，原课程表提醒仍可使用。
- 内置 77 万余条离线英汉词典词条，无网也能查询释义、音标、词形并朗读。
- 用本地 FSRS 6 进行语境背词：从 `original36` 原创 36 词入门包开始，也可导入自己的词表；粘贴自己的阅读材料，从每天半页开始，在原句中查词、收藏上下文。阅读与复习记录由本人确认并保存在本机，也可自行导入导出。
- “我的学校”复用已登录的 ManageBac／EduPage 会话，只读查看按教学组筛选的具体日期课表、课程、总评、作业详情与 CAS／EE 摘要，并可预览后把日期课表导入本地计划。该功能尚未用真实学生账号完成验证，成绩和安排必须以原网页为准。
- 提供按科目、考试版本与 AO 查询的 IB 指令词、写作字数统计、加权成绩计算、EE／TOK／IA 里程碑模板，以及 IB 官方课程页、官方样卷和 IB Docs 外部入口。
- 支持自定义全局快捷键，常用页面和工具可以快速唤出。

## AI 是可选的

不用 AI，PH Launcher 的学校网站入口和全部本地工具仍然可以完整使用。

需要时，可以选择本地 AI 或 API AI。PH Launcher 会根据每台电脑自己的内存、显卡和磁盘空间给出本地模型建议，符合条件时可一键部署推荐模型；配置较低的电脑会明确建议不要安装。

“AI 操作启动器”默认关闭。开启后，AI 可以帮助整理任务、笔记和课程表，也可以从已经打开的 EduPage 常规课表生成导入预览，或按名称打开已经添加的网站。任何数据更改都会先列出完整内容，只有本人确认后才保存。AI 不能读取自选网页内容、填写网页表单，也不能读取密码、Cookie、验证码或 API Key，不能删除资料、发送邮件或提交作业。

## 隐私与安全

学校账号密码默认由原网站处理。只有本人主动同意时，PH Launcher 才会用当前系统用户密钥加密保存账号记忆，并仅在学校邮箱、ManageBac、EduPage 三个固定站点的登录页填入，绝不会自动提交；密码不会交给 AI 或写入备份。笔记、任务、课程、词本、阅读和专注记录默认保存在本机。云端 AI 可能接收你主动提交或明确授权的数据，因此不要发送账号密码、验证码、他人隐私或不应上传的作业材料。

PH Launcher 是学生协作项目，不是上海市民办平和学校、ManageBac、EduPage 或网易的官方产品，也不使用校徽。

IB Docs 是第三方网站，与 IBO 无隶属或背书关系，可能包含受版权保护的资料。PH Launcher 只在系统浏览器中打开它，不下载、内嵌、缓存或索引资料；仅在学校或权利人明确授权的情况下访问和使用。

项目已经开源。请从 [GitHub Releases](https://github.com/XKRyan/PH-Launcher/releases) 选择实际存在的最新版本，并核对发布页中的 SHA-256。本文不表示 `0.6.0-beta.1` 已经上传，也不表示 Mac 包已经构建；可下载平台与附件以实际发布页为准。

若实际发布页提供标有 `mac-preview` 的 macOS 包，请按该页面说明确认系统要求、签名与公证状态，只转发完整预发布页，不要单独转发来源不明的安装包。

本次协作预览没有移植 Hello Pinghe! Launcher 的全部功能。独立邮件客户端／通讯录、AI 代发邮件或代交作业、Word 起草、任意班级查询和四种新代理权限模式仍是愿望清单；学校网站原生页面仍可照常使用。
