# PH Launcher 1.0.10

本版继续完善学习记录、离线使用与 AI 操作能力。

## 新增与改进

- 背单词将词汇明确分为“已学会”“已学习（下次复习）”和“暂停复习”，并显示下次复习时间。
- 学词进度实时保存，包括当前预览位置、剩余词组和回忆阶段；中途退出或重启后可以继续。
- 最近成功读取的课表与学校内容保存在本机，断网时仍可查看上次结果。
- 背单词 API 授权可选择在本机记住，也可随时在连接设置中撤销。
- 修复“我的表达”无法保存的问题。
- AI 对话记录损坏时会隔离异常文件并自动建立新的加密记录，避免整个对话区无法继续使用。
- AI 完整权限新增日程删除：必须先读取真实日程，并以准确 ID 生成待确认清单；确认后才会删除。重复日程会明确提示整组删除。
- 完善首次使用导览、中英文界面、学习入口和心理模块相关提示。

## 安全说明

- AI 仍不能读取密码、Cookie 或授权码。
- 所有写入与删除操作仍须由用户确认；日程在确认前发生变化时，旧操作会自动失效。
- Windows 安装包目前没有商业代码签名，系统可能显示“未知发布者”。请从发布页下载并核对 SHA-256。
