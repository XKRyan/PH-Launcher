已实现的事实（只使用这些）：

1. 我的课程成为学校学习入口：课表、课程、通知、任务、讨论、CAS／EE 放在同一工作区。课程内可查看概览、单元与计划、任务、日历、讨论和文件；返回及切换时保留位置，重启后可恢复上次所在栏目、周次及课程。
2. 手动选课及课程关联长期保存，修复重启后恢复自动选择的问题。课表课程可以进入对应 ManageBac 课程查看任务；通过当前用户已登录的 ManageBac 会话读取周课表，优先按日期和时间定位课程编号。唯一匹配自动关联，有冲突或网站未提供数据时保留确认和更改入口，已手动更改的关联优先。
3. Assessment、Coursework、Event 统一称为任务。区分任务类型、是否需要提交和实际完成状态；已经发布成绩的测验，包括 0 分，不再因旧提交标签显示逾期。明确要求重新提交的任务仍会提示处理。任务默认按最新时间优先排列。
4. 课程单元按单个单元读取，去掉重复 unit id；概览只显示有限预览，单元页显示完整卡片，包含可用日期、时长、级别和状态，并可回到对应原网页。旧版扁平缓存不再直接渲染；读取失败与确认没有数据分开显示。
5. 任务说明保留段落、有序／无序列表、嵌套列表、自定义起始编号、反向编号及字母／罗马数字标记；列表项里的图片仍留在该项内。旧缓存会在下一次成功同步后获得新结构。
6. 任务详情只把真正的说明正文当作“任务要求”。课程名、截止日期、Summative／Coursework 等徽标、Dropbox 等页面标签不再混进正文；没有可读正文时明确显示“未读取到任务要求，请在原网页核对”，不再用元数据拼出看似正文的内容。
7. 识别到 Not Submitted／Pending 的 Dropbox 任务时，任务详情提供应用内选择文件并确认上传的入口：先核对课程、任务与文件，再点“确认并上传”；只选择文件不会上传。页面没有暴露可用上传表单时，保留“去原网页提交”。上传请求完成不等于学校确认已提交，程序不会自动重试，也不会替用户标记为已提交。
8. 增加手动刷新及刷新中反馈。学校页面每 5 分钟检查是否需要更新，ManageBac 缓存 3 分钟、EduPage 缓存 2 分钟；缓存失效不意味着每分钟发网络请求。后台任务提醒每 10 分钟检查一次，托盘运行时继续工作，完全退出后停止。
9. 新任务和临近截止提醒可配置，触发应用弹窗及 Windows 系统通知；点击通知可进入任务。按任务合并提醒，已完成、已提交或已隐藏的任务移出待办提醒；首次同步不会把历史任务全部当成新任务。通知展示仍受系统通知权限和勿扰设置影响。
10. 修复同步后出现 `input is not defined`、任务读取不完整、慢请求一直等待、旧请求覆盖新课程等问题。网络异常时保留已读取内容并提示状态，避免把读取失败说成“没有任务”。
11. 内置背单词入口改为 VLMReader：已安装时直接打开；未安装时展示下载页，默认提供国内 GitHub 中转下载来源，也能选择官方来源。新版移除 PH Launcher 的离线词典入口和随包词库，旧背单词记录保留并可导出。
12. AI 学习助手支持本地 Ollama 与 OpenAI-compatible API，回复流式显示，思考过程单独成块，支持 Markdown 与 LaTeX。v2.0.11 为本地 Ollama 增加“思考模式”开关，可随时开启或关闭；开启后使用模型自己的 thinking 输出并提高输出预算，关闭后保持快速回答。
13. 更新统一 PHL 图标，精简导航、设置及部分弹窗，改善小窗口布局；移除重复的 CAS／EE 嵌套区块和页面控件。修复重复云同步连接、错误密码反复自动登录等问题，加强链接、附件和操作来源检查。
14. “设置 → 关于 → 作者信息”最前面加入 GitHub 主页与邮箱；README 与 package.json 同步作者链接。
15. Windows 和 macOS 都有安装包；Windows 安装包未签名，macOS 使用临时签名、未经过 Apple 公证。请以实际 Release 页面和安装包说明为准，不要写成所有平台都已公证。
