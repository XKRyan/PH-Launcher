## 更新介绍版（约 400 字）

PH Launcher 2.0.11 已发布。相比 v1.0.15，本次更新主要集中在学校学习入口、任务与提交、提醒同步、AI 与配套工具，以及界面和稳定性。

**学校学习入口。** 课表、课程、通知、任务、讨论、CAS／EE 集中到“我的课程”；课程内可查看概览、单元、任务、日历、讨论和文件；重启后恢复上次栏目、周次和课程。手动选课与课表课程关联会长期保存。

**任务与提交。** 任务统一区分类型、提交要求和实际状态；任务说明保留段落、列表和列表项图片；详情只显示真正的作业要求，没有可读正文时会明确提示。识别到未提交的 Dropbox 任务时，可在应用内选择文件，核对课程、任务和文件后确认上传；上传完成不等于学校确认，最终以原网页为准。

**提醒与同步。** 支持手动刷新、缓存和后台提醒；新任务与临近截止可触发应用弹窗和 Windows 通知，已完成或已隐藏的任务不再提醒。

**AI 与工具。** 内置背单词入口改为 VLMReader；AI 支持本地 Ollama 与 API、流式回复和思考过程，2.0.11 为本地 AI 增加思考模式开关。

此外，2.0.11 修复了任务详情解析、慢请求、旧请求覆盖新课程等问题，并调整了导航、设置和小窗口布局。
