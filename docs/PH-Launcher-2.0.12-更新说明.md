# PH Launcher 2.0.12 更新说明

发布日期：2026-11-09

这一版主要修账号登录、云同步和界面信息不一致的问题，另外把整个软件里同类的小毛病一起排查了一遍。

## 首次打开

- 登录页现在有醒目的 **「暂不登录，先使用」**，不想登录也能直接进入软件（「暂时跳过」也还在）。
- 首次打开与登录界面改成和软件一致的米白 / 墨绿配色，并补上入场、进度条、按钮等动画。
- 「我们正在为你准备你的软件」改为 6 个真实步骤（同步 → 账号 → 学校 → 课表 → 日程 → 资料），
  同步失败会如实标红并说明原因，不再是一条假进度。

## 账号与云同步

- 修复「设置里显示账号未登录，云同步面板却显示已登录 / 已同步」。
  现在账号卡片、云同步面板、首页、AI 页读取同一份状态，登录、退出、同步后一起刷新。
- 修复「首次进设置显示未登录」「刚进软件说没有同步信息，其实已经同步」。
- 修复有登录令牌时启动仍弹登录页的问题；密码模式会自动解锁并继续。
- 修复设置页里本该隐藏的「独立同步口令」输入行一直显示。

## AI 配置

- `AI 供应商与 Key` 现在默认参与云同步：在网页端 / Pinghe Launcher Lite / 客户端任一处配置，
  登录后其他设备会自动拉取并启用；登录时也会把本机旧配置补传到云端。
- 修复空 AI 配置每轮同步都空推一次、云端版本号不断上涨的问题。

## 其他一致性修复

- 头像：Profile 里有头像现在能正常显示；退出登录后不再继续显示上一个账号的头像；
  头像同步失败不会再提示「已同步」。
- 心履：登录 / 退出 / 后台同步后，应用其他位置的心履状态会跟着刷新；心履设置保存补上了后端接口。
- 本机词典：数据缺失时词汇页会提示手动填写释义，不再报「查询失败」。
- 底部按钮 / 输入行等设置了隐藏却仍显示的问题统一修复（例如首次引导的「上一步」）。
- 启动画面计时脚本改为外部文件，消除 CSP 内联脚本报错。

## 说明

- Windows 安装包未签名；macOS 为 ad-hoc 临时签名、未公证，首次打开可能需要在
  「隐私与安全性」里允许。
- 本版本为测试与修复版本，真实学校提交作业 / 发信仍建议核对后再操作。
