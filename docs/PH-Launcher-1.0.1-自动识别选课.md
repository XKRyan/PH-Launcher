# 自动识别选课

在“我的课表”点击“自动识别选课”。还没同步 ManageBac 时，按提示同步已选课程；匹配出的教学组会自动勾选，核对后点“保存选择”。不需要逐门重新输入课名。

- 区分 HL／SL、数学 AA／AI，兼容对应课程全称。
- 学校页面提供明确老师姓名时，结合老师进一步匹配教学组；缺少信息时不会猜测。
- 保留你已经手动选择的课程，只补充还没有选择的科目。想修改已有科目，请手动调整勾选。
- 同科存在多个可能教学组，或找不到对应课程时，会列出需要确认的项目。
- 仅修改启动器内的课表筛选，不会向学校提交选课变更，也不调用 AI。

请确认 ManageBac 与 EduPage 登录的是同一位学生。跨网站匹配不是学校出具的个人选课证明，最终以自己的实际选课与老师安排为准。识别仍需你核对并保存，不会在后台无提示替换课表。

本次先提供 Windows 1.0.1；之前的 Windows／Mac 1.0 安装包保持不变。
