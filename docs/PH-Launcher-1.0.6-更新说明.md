# PH Launcher 1.0.6

- 「计划」只保留任务和专注，移除重复的手动课程表入口及学校页面的旧导入入口。
- 「我的日程」继续管理有时间的活动与每周重复；「我的课表」继续展示学校课程。

没有合并、迁移或删除已有用户数据。旧计划课程表数据仍保留在本地存储和备份中，但不再提供原编辑入口；本次也没有删除用户已有的任务。
